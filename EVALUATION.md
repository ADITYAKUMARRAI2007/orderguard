# Evaluation

Run `make eval` for the seeded gate benchmark, injection curve, baselines,
cart Attack Lab, and agent-boundary Attack Lab. The command regenerates
`docs/BENCHMARK.md` and `results/latest.json` and exits non-zero on unsafe
acceptance.

Run `make feature-matrix` separately to regenerate the code-derived feature
inventory. A clean checkpoint also runs `uv run pytest -q`.

`make eval` now also writes `results/connector_routing.json` and
`results/runtime_parity.json`. Current limitation: visual-E2E and final judge
JSON artifacts requested by the master build are still not generated by
`make eval`; the feature matrix reports that gap rather than inventing data.
